# HackFlow — платформа студенческих хакатонов

Демо-пространства двух мероприятий — открытого «Актион HackFlow Challenge 2026» и закрытого «Башкортостан Digital Sprint 2026». У каждого хакатона свой организатор; закрытый хакатон виден владельцу и экспертам, принявшим приглашение. Вход и регистрация обычных аккаунтов работают через Supabase Auth. Данные хакатонов и рабочие данные демо-приложения пока хранятся в `localStorage` текущего браузера и не синхронизируются между пользователями или устройствами.

## Запуск

**Вариант 1 — проще всего.** Откройте `index.html` двойным щелчком в браузере.

**Вариант 2 — локальный сервер** (нужен Python 3):
- Windows: запустите `start.bat`
- macOS / Linux: `./start.sh`
- или вручную: `python3 -m http.server 8000 --bind 0.0.0.0`, затем откройте http://localhost:8000/index.html

Регистрация через Supabase может требовать подтверждения почты. Для опубликованной версии укажите адрес сайта в настройках Supabase Auth → URL Configuration (Site URL и Redirect URLs), чтобы ссылки подтверждения возвращали пользователя в приложение.

### Открыть HackFlow на телефоне

1. Подключите телефон и компьютер к одной Wi-Fi сети.
2. Запустите `start.bat` (Windows) или `./start.sh` (macOS / Linux). Сервер слушает подключения в локальной сети. Если порт 8000 занят, Windows-скрипт выберет свободный порт из диапазона 8000-8010.
3. На Windows используйте один из готовых адресов для других устройств, напечатанных `start.bat`. На macOS / Linux узнайте локальный IP командой `ifconfig` или `ip addr`.
4. В браузере телефона откройте `http://IP-КОМПЬЮТЕРА:ПОРТ/index.html`, например `http://192.168.1.25:8000/index.html`. Устройства должны быть в одной Wi-Fi сети; если Windows запросит разрешение брандмауэра, разрешите доступ в частной сети.

Интерфейс адаптируется к экрану телефона. На сайте, опубликованном по HTTPS, HackFlow можно установить на главный экран как PWA; локальный адрес по HTTP подходит для запуска в браузере той же Wi-Fi сети.

19 участников распределены по шести командам открытого хакатона. Демо заранее заполнено задачами, расписанием, учебными материалами, отправленными проектами и закрытыми оценками, чтобы ревьюер мог пройти сценарий без подготовки данных. Аккаунты экспертов подтверждены; приглашение на закрытый хакатон ожидает ответа в уведомлениях. Эксперт может оценивать только хакатоны, приглашение на которые он принял. Пароли предназначены только для демонстрации.

Демо-профили участников указывают университет УУНиТ и факультет ИИМРТ. При регистрации поля университета, факультета и группы пусты. Эксперты также заполняют поле «О себе»; организатор видит это описание при поиске эксперта по точной почте, а участники — в обзоре хакатона после принятия приглашения. Эксперта можно пригласить или отозвать из кабинета организатора; приглашение принимается в его уведомлениях. Университет выбирается из локального списка 1 367 вузов и филиалов; поиск находит название по любой части имени или сокращения. Ввод несуществующего значения не принимается. Формат группы не ограничивается. Список включён в приложение, поэтому поиск работает без отправки запросов сторонним сервисам.

Каталог объединяет 1 257 организаций и филиалов из мониторинга Минобрнауки России за 2025 год (снимок от 05.11.2026) и ещё 110 действующих аккредитованных организаций, отсутствующих в этом каталоге (реестр Рособрнадзора от 10.11.2026). Источники: [мониторинг Минобрнауки](https://monitoring.miccedu.ru/?m=vpo&year=2025) и [открытые данные реестра аккредитации Рособрнадзора](https://isga.obrnadzor.gov.ru/accredreestr/opendata/).

## Основные сценарии

1. Войдите как капитан FlowMakers (`participant01`). Откройте открытый хакатон, изучите кейс, задачи, расписание, образовательный трек и приватный чат команды.
2. Перейдите в кабинет организатора (`organizer`). Создавайте хакатоны во вкладке «Создать новый хакатон», а созданные открывайте в отдельных вкладках. В карточках команд раскройте подробный прогресс: выполненные материалы по каждому модулю и участнику, а также доску задач только для чтения. Финалистов отмечайте чекбоксами и отправьте результаты; после публикации список изменить нельзя. Экспертов можно приглашать чекбоксами в любое время, а активные приглашения — отзывать. Опубликованные учебные материалы можно изменить или удалить.
3. Войдите как организатор Башкортостан Digital Sprint (`organizer2`). Убедитесь, что в кабинете отображается только его закрытый хакатон.
4. Войдите как эксперт (`expert1`), откройте приглашение на закрытый хакатон в уведомлениях и примите его. После принятия хакатон появится в кабинете эксперта; до принятия команды и оценки недоступны.
5. Войдите как ментор (`mentor`). Он прикреплён к FlowMakers, видит материалы только этой команды и может оставлять ей комментарии, но не управляет хакатонами и не выставляет оценки.
6. Проверьте аккаунт участника FlowMakers (`participant02`): материалы команд, оценки экспертов и закрытый лидерборд ему недоступны. Уведомления приватны и разделены по типам.

В открытом демо-хакатоне — «Актион HackFlow Challenge 2026» — находятся шесть команд, их проекты, полуфинальные оценки, задачи, расписание и учебные материалы. Полуфинал и финал оцениваются отдельно по шести критериям каждый, по шкале 0–5; эксперт оставляет закрытый комментарий, оценки и лидерборды доступны только организатору и принятым экспертам. Организатор выбирает финалистов и публикует для каждой команды персональное уведомление о результате. При создании и редактировании хакатона задаются площадка, формат финальной защиты и место/ссылка финала. «Башкортостан Digital Sprint 2026» принадлежит второму организатору и закрыт от остальных аккаунтов, пока эксперт не примет адресное приглашение. Общий чат предназначен для поиска команды и вопросов об открытом мероприятии; командные материалы доступны участникам только своей команды и назначенному ей ментору. Ментор может читать материалы и писать комментарии, но не оценивать проекты или управлять хакатоном.

Оценки экспертов и лидерборд сохраняются локально вместе с остальными данными демо. Ролевое скрытие интерфейса не заменяет серверную авторизацию: в этой версии нельзя считать данные защищёнными от пользователей, имеющих доступ к браузеру.

В личном кабинете доступны восемь цветовых палитр, каждая в светлом и тёмном варианте. Режим можно выбрать вручную или настроить по системе; палитра и вариант оформления сохраняются в браузере.

## Файлы
- `index.html` — разметка
- `style.css` — стили (светлая и тёмная темы, адаптив)
- `auth.js` — подключение Supabase Auth и публичный ключ клиента (не размещайте здесь `service_role` или другие секретные ключи)
- `app.js` — данные, логика и отрисовка (демо-данные в начале файла)
- `university-list.js` — поисковый каталог вузов и филиалов
- `manifest.webmanifest`, `service-worker.js`, `icon.svg` — установка и офлайн-кэширование PWA

## Разделы
Главная с доступными хакатонами и поиском по названию (включая кириллицу), мои хакатоны, уведомления, кабинет организатора, пространство эксперта и личный кабинет. Вкладка личного кабинета расположена внизу меню. Созданные хакатоны доступны для поиска, а регистрация открыта до указанного срока; существующие закрытые демо-хакатоны по-прежнему видны только пользователям с доступом. Участникам доступны обзор, команда, задачи (Kanban), обучение, расписание, общий и командный чаты, а также сдача проекта. Организатор управляет только собственными хакатонами; эксперт видит закрытый хакатон после принятия приглашения.

## Ограничения

Это демонстрационный прототип: аккаунты управляются Supabase Auth, но профили приложения, команды и остальные данные доступны только в текущем браузере и не синхронизируются между пользователями или устройствами. Проверки доступа в интерфейсе не заменяют серверную авторизацию: данные `localStorage` можно прочитать через инструменты браузера. Для совместной работы и защищённых данных нужны база данных Supabase и серверные политики доступа (RLS). В MVP срок сдачи задан для демонстрационного хакатона.
